# 订阅账期与提醒计划

保留订阅模型、月末/闰年账期、月年等价费用、归档节省估计、试用/续订提醒计划和CSV/JSON生成。无真实账户、支付、自动续订或系统通知。

这是独立Swift Package，无网络依赖和原目录依赖；macOS 14+、Swift 6工具链。只含Foundation业务模块与CLI，未附原iOS界面、Widget、照片、签名、App Group或通知权限代码。没有默认读取个人数据的路径。源码采用 MIT 许可证，见 LICENSE。

```bash
swift test
swift run planner example.json
```

CLI读取唯一显式JSON文件并把结果写标准输出；不覆盖文件、不保存状态。库公开API可接自定义完整模型。所有示例合成，日期按UTC日历计算。`start`/`today`日期必须明确给出，结果不代表已订阅/已通知/已执行排班。

源组件与测试对应关系保留在本次私有审计清单；本包不带用户绝对路径。实际测试采用独立临时副本和系统沙箱，原iOS/通知UI未启动。

## 输入与账期边界

`price` 必须是完整的非负十进制字符串（最多38位数字，可有小数点）；不接受空白、指数、尾随文本、NaN或负数。`custom` 必须明确给出正整数 `custom_days`，不能缺省、为零或负数；不再隐式换成1天/30天。非custom若提供周期数，也必须为正。

`amount_due_this_month` 按币种分别计算 `today` 所在的**完整自然月**：包括月初当天，排除下月月初，枚举当月全部应到期序列。`today` 只选择月份，不表示已付款截止点；已归档订阅全部跳过，不还原归档前的账务。周订阅首账2030-01-02、每次10时，1月2/9/16/23/30共50。无需推断试用抵扣或真实支付状态。

`nextBillDate(after:)` 仍返回严格晚于给定日的下一次账期；月末始终按原首账日锚定，不从二月短月永久漂移。月/年等价金额是折算估计，与实际自然月到期次数总额不同。

核心构造和账期API现在会抛错，库调用须使用 `try Subscription(...)`、`try BillingMath.nextBillDate(...)`、`try BillingMath.amountDueThisMonth(...)`，月/年等价属性也使用 `try`。这在原始数据模型被调用方修改后仍会检查无效周期。

17项XCTest与9个实际CLI用例在临时副本、空HOME、禁止网络/原目录读取的系统沙箱中通过；原月末/闰年/提醒导出测试继续保留。CLI回归需要Python3标准库：先 `swift build`，再 `python3 scripts/cli_cases.py`。没有启动iOS UI或发送真实提醒。

CLI中的 `amount_due_this_month` 表示“本月计划到期总额，含今天以前，未推断已付/待付”；同名说明字段随结果输出。此口径修正了原实现只取下一次账期、漏掉月内重复到期的问题，并明确采用完整自然月合同，未宣称完全复刻原语义。
